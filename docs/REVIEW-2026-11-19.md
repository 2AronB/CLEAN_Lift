## Navigation design (implemented)

Four tabs, Workout first and the default:

| Tab | Was | Holds |
|---|---|---|
| **Workout** | Workout | Start/log/finish |
| **Plans** | Templates | Plans, exercise library, generator |
| **Progress** | Metrics | History, strength, body, health metrics |
| **Tools** | Widgets | Timers, calculators, PACER/HAMR, AF, benchmarks |

Settings left the bar and is a gear icon in each tab's top bar. It opens full screen and
Back returns to the tab you came from, with that tab's state kept. Rationale: Settings is
rarely visited; four destinations give each label room at large text sizes, and the
preferences favor compact supporting navigation. Workout moved first because it is
the primary action and fresh launch already opens it. Internal names (Metrics, Templates,
Widgets) remain in code, prefs and backups so no data or backup format changes.

## Palettes (implemented)

Settings > Appearance: **Theme** (System / Light / Dark) and **Palette**:

- **Iron** (default) — charcoal neutrals with an ember orange accent and steel blue.
- **Chalk** — strong pastels: lilac, mint, peach; dark text on pale fills.
- **Forest** — deep greens with brass.
- **Wallpaper** — Android 12+ dynamic color; falls back to Iron on older phones.

Stored as two string keys in the existing `local-profile` preferences, validated by
`BackupPreferences`, so they travel with backups. Older backups without the keys still
restore (defaults apply). No schema change.

## Rebrand plan

**Status 2026-11-20:** owner picked **CLEAN Lift**; step 3 is done (D-013). Steps 2, 4 and 5 are owner steps, listed in [CONTINUE](CONTINUE.md).

Steps, in order:

1. Owner picks the name.
2. Owner makes a JSON backup on the phone (Settings > Backup & restore) and keeps the file.
3. Change `applicationId` and namespace to `dev.clean.lift`, display name, package folders.
   Android treats this as a **new app**: the old Workout Logger stays installed with its
   data untouched until you uninstall it.
4. Restore the backup into the new app; compare history; only then uninstall the old one.
5. Move the folder to `CLEAN Development\CLEAN Lift` (close Android Studio first; Gradle
   caches rebuild). Update AGENTS.md paths.

Why not now: steps 2 and 4 happen on your phone, and the name is yours to choose. The code
change itself is mechanical (about an hour) once the name is picked.
