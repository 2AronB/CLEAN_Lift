# Milestones 6 and 7: workout builder and guided logging

Milestone 5's manual checks 1–9 passed, as reported by the user. This update adds Finish workout to the exercise picker's top-right corner, reusable templates, and guided logging. No new libraries, permissions, SDK components, or emulator setup are needed.

## Install

Open this folder in Android Studio. Select **app** and the existing **Medium Phone** emulator in the toolbar. Choose **Run > Run app** or press **Shift+F10**. Wait for the updated app to open. Do not uninstall or clear app storage: normal updating preserves existing data.

## Acceptance checklist

1. **Old data:** open Exercises and History. Confirm previous names, workouts, and corrections remain. Start an empty workout, save one set, tap **Next exercise**, then tap **Finish workout** at the picker's top right. Confirm it appears in History. No extra set should be saved by Next exercise.
2. **Builder:** open **Templates > New workout**. Name it **Workout A**. Add Bench Press and Squat. Choose **Fixed sets**, enter **2** for Bench, and choose **Until done** for Squat. Tap Save. Create **Workout B** with two other exercises. Expect both workouts listed.
3. **Edit/reorder/validation:** tap Workout A to edit it. Use **Move up/Move down** to reorder, then restore Bench first and Squat second. Remove an exercise and add it back; restore the intended plan. Blank name, duplicate name ignoring case, no exercises, blank fixed sets, 0, and 100 should not save. Leave a changed draft using Back; check Keep editing and Discard. Rotate while editing and confirm the name, order, and set choices remain.
4. **Start/order:** tap **Start** beside Workout A. Expect the Bench editor first and **Saved: 0 · Planned: 2**. Next exercise should be gray. A short tap should do nothing; do not hold yet. Save **185 lb × 8**, then save **185 lb × 7**. Expect Next exercise active and Save extra set gray. Tap Next exercise: expect Squat, not the alphabetically next exercise.
5. **Until done/finish:** save one or more Squat sets; there should be no fixed-set limit. Tap Next exercise to mark Squat done. Expect the picker with Finish workout top right. Tap Finish. History should show Workout A, its actual sets, and no override marker for this normal run.
6. **One extra set:** start Workout A again, save Bench's two sets, and press/hold gray **Save extra set** for about a second. Expect exactly one extra saved row and **Plan overrides: 1**. Short-tap Save extra set again: no new row. Hold again: one more set and overrides 2. Next exercise should still follow the template. The number is retained in History after finishing.
7. **Skip only once:** start a fresh Workout A. Before saving Bench sets, hold gray Next exercise. Expect Squat and overrides 1. Before saving any Squat set, short-tap Next exercise: it must still be blocked. Save a Squat set, tap Next, and finish. Expect Bench retained as **No sets logged** in History and the override count retained. The first override must not unlock the next action.
8. **Finish early:** start Workout A, save one Bench set, tap Back to the active screen, and short-tap gray Finish workout: stay active. Hold Finish workout: finish early with one override. No invented sets should appear. Finish should remain completely unavailable before any set has been saved, even when held.
9. **Deviation/recovery:** start Workout A. From the active overview, hold Add exercise, choose another lift, and confirm an override marker appears. If earlier exercises are unfinished, saving a set out of order requires holding the gray Save set button. Removing a planned exercise also requires a hold followed by its existing removal confirmation. Each completed deviation increments once. Cancel and confirm older completed workouts remain.
10. **Restart and template independence:** start Workout A, save a Bench set, then force-stop (emulator Settings > Apps > See all apps > Workout Logger > Force stop > OK). Reopen and tap **Continue planned workout**: expect Bench's retained values, saved set, and target of 2. Go to Templates and edit Workout A's order/count, or delete it. The active workout must keep its original order/count/name. Finish or cancel the active workout before starting a different template.
11. **Keyboard/display:** try dark mode and rotation in builder and set entry. Open the keyboard and scroll to the save controls. Keyboard Done should save one valid set, but cannot bypass a gray plan action. Invalid weight/reps cannot be overridden. Check that the gray actions explain holding and the override indication is readable. With TalkBack, their long-click action should be available; this accessibility interaction remains a manual check.

Editing a saved set corrects it without creating another set or recording a plan override. Removing a set reopens that exercise's guidance. Only deliberate deviations count as overrides. Holding grants permission to one action, never a session-wide unlock. A hold on Add exercise selects one extra exercise; backing out cancels that pending choice. Fixed counts currently support 1–99 sets and templates up to 100 exercise entries. Rep-range targets, supersets, tags, and rest timers remain deferred.

Automated checks cover plan rules, ordering, transactions, snapshot isolation, persistence, one-action overrides, and populated migrations from versions 1 and 2. UI tests are intentionally manual.
