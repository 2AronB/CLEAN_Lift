# History, progress, measurements and template convenience

## Install

Open this folder in Android Studio. Select **app** and **Medium Phone** in the toolbar, then **Run > Run app** or **Shift+F10**. Existing data should remain. No SDK/dependency setup changes are required.

If Medium Phone cannot start correctly or Android shows system errors, open **View > Tool Windows > Device Manager**. Stop that emulator, open its three-dot menu and select **Cold Boot Now**. Do not choose Wipe Data, uninstall, or clear app storage for persistence tests. This iteration encountered an Android system crash from the emulator's quick-boot snapshot, recovered with a cold boot preserving data.

## Acceptance checks

1. **History browsing/search:** previous workouts and corrections remain. Named template workouts show their names and dates. Search a workout name or a saved exercise name; type several characters and confirm input/keyboard stay usable. Clear the search and confirm the full list returns. A name with no match should have a useful empty state.
2. **Exercise plots:** finish two workouts containing the same lift, one with **200 lb × 5**, the other **175 lb × 10**. Open **History > Exercise progress**, search/select that lift. Expect separate workout points and session rows. Choose kg/lb and 90 days/1 year/All time; only display units change. Tap a session and confirm it opens the correct historical workout. Back returns to that exercise's chart with filters retained; further Back presses return through the exercise chooser to History.
3. **Estimated 1RM:** in progress, choose Estimated 1RM and 5 reps or 10 reps. Each new attempt above should display approximately **233.33 lb** for its own session; older all-time records may be higher. Rows beneath the chart provide numeric estimates. Bodyweight sets recorded as external weight 0 should not produce an estimate. Correct a completed set in history, then reopen progress and confirm updated values.
4. **Break scenario:** expand Explore a break scenario. Default 0% should retain the latest eligible estimate. Adjust the monthly-loss assumption and confirm only the what-if result changes; historical points/records remain unchanged. It should explain that this is an assumption, not a prediction, and lack of logs does not establish inactivity.
5. **Bodyweight:** open **History > Body measurements > Add measurement**. Enter **2026-10-01**, **185.125 lb**; save. Add **2026-10-02**, **184 lb**. Expect date-ordered points, newest entry first, and change of **-1.125 lb** (display rounded to -1.13). Switching to kg should convert the view. Tap the first record: expect the original 185.125/lb entry, not a rounded converted number.
6. **Other measurements:** use the metric dropdown to choose Waist. Add **2026-10-01**, **35 in**. Switch view to cm: expect **88.9 cm**. Add left and right biceps entries and verify they remain separate. No workout or bodyweight record should change.
7. **Edit/delete/validation:** edit a measurement's value/date, save, reopen and verify. Try a duplicate metric/date; expect a useful error and no overwritten record. Reject impossible/future dates, zero/negative values, and more than 3 decimals. Delete one measurement with confirmation; only that record disappears. Change a draft and test Back > Keep editing/Discard.
8. **Template duplication:** open an existing template, tap Duplicate workout, rename it, adjust one exercise/count and Save. Expect the original and new template independent. Cancel another duplicate draft; no new template should be saved. Starting the original should retain its original plan.
9. **Previous workout values:** start an empty or template workout with a lift used previously. In set entry, expect a dated Previous workout reference. Tap Use previous workout values; confirm exact reps/weight/unit copied, but no set saved until Save set. Change the draft and tap Use previous again; test Keep/Discard. After one current-workout set, adding the next set should still default to the current workout's last set. A lift with no completed history should not invent starting values.
10. **Persistence/display:** force-stop via emulator Settings > Apps > See all apps > Workout Logger > Force stop > OK, reopen, and confirm workouts, templates and measurements remain. Rotate during a measurement/template/set draft; confirm it remains. Try dark mode, open keyboard and increased font size, checking controls remain readable/reachable. Chart values remain available through readable list rows. Repeat a save in airplane mode if desired.
