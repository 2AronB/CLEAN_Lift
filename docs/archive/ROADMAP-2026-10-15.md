## Implemented in this update; manual acceptance pending

### Milestone 6 — Streamlined workout builder

Named reusable templates; add/remove/reorder exercises; fixed set counts or Until done per exercise; create several workouts and start any one. Name/plan validation, discard protection, saved drafts across rotation, template deletion, and data-preserving schema-3 migration. Starting copies the plan and current exercise names into a workout snapshot. Editing/deleting the template cannot rewrite the active workout or history.

### Milestone 7 — Guided logging and focused interaction polish

Continue a planned workout; advance through its explicit order; fixed set targets; user-controlled completion for Until done; finish from the picker's top right. Gray plan actions accept a deliberate long press to override **only that action**. Store an override count and show it in the active workout and history. No blanket override mode. Plan deviations can add an extra set, skip/advance early, add/remove an exercise, or finish early. Invalid values and a workout with no saved sets stay blocked. Empty-start workouts retain their manual picker flow.

The original Milestone 7 polish scope is partially addressed here through draft preservation, clear progress/override guidance, keyboard guards, and accessible long-click actions. Wider accessibility, visual, and real-device validation remains the next milestone.

Use MILESTONES-6-7-TESTS.md for this update's manual checks.

## Proposed later milestones — not implemented or automatically authorized

### Milestone 8 — Finish core polish and reliability

Respond to manual feedback, test on a physical phone when useful, review TalkBack/font scaling and compact layouts, measure startup/scrolling if needed, and improve error/recovery paths. Add optional previous-workout value references only after the core flow is accepted and the scope is agreed.

### Milestone 9 — Local data portability

Explicit export/import with preview and validation, a documented durable file format, and preservation tests. Decide Android backup/device-transfer policy separately. No cloud backend or Internet permission.

### Milestone 10 — Optional superset workflow

Group exercises and alternate next-set entry while retaining each exercise's previous values. Resolve grouping, sequence, targets, skipping, and plan override behavior before changing the schema. Deferred tags can be considered independently; no tags are required for templates or supersets.

RPE/notes entry, rep ranges, rest timers, PR calculations, and charts remain separate backlog choices. Nothing listed here should trigger unrelated implementation.
